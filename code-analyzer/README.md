# Code Analyzer

Applies the shared lifecycle to review findings generated by
`code-review`, `ai-code-review`, or another review tool:

- loads a JSON array or an object containing an `items` array;
- filters by severity and applies the configured comment limit;
- de-duplicates findings using stable fingerprints;
- skips existing open comments and auto-marks stale comments as fixed;
- posts inline comments through [`post-file-comment`](../post-file-comment/);
- enforces the configured fail level.

## Usage

```yaml
- uses: actions/forgejo/code-analyzer@v1
  with:
    items-file: review-items.json
    message-template-file: templates/review-comment.md
    level: warning
    fingerprint-mode: lint
    fingerprint-prefix: lint-review
    skip-existing: true
    fail-level: warning
    token: ${{ github.token }}
```

## Input JSON

The file must contain either a JSON array or an envelope:

```json
{
  "items": [
    {
      "path": "src/app.py",
      "line": 42,
      "severity": "warning",
      "message": "Handle this error explicitly."
    }
  ],
  "summary": {
    "model": "example-model",
    "files_reviewed": 1,
    "notes": []
  }
}
```

Every item requires `path`, `line`, `message`, and `severity`. Additional
fields are preserved for the message template. An envelope's `summary`
metadata is used when `review-body` is empty.

## Inputs

| Input | Default | Description |
| --- | --- | --- |
| `items-file` | required | JSON array or review envelope. |
| `message-template-file` | required | Template used to render each item. |
| `review-body` | `""` | Top-level summary; empty uses producer metadata when available. |
| `path-field` | `path` | Dotted path to the file path in each item. |
| `line-field` | `line` | Dotted path to the 1-based line number. |
| `level` | `none` | Minimum severity to post: `none`, `info`, `warning`, or `error`. |
| `skip-existing` | `true` | Skip open fingerprints and auto-mark stale comments fixed. |
| `max-comments` | `0` | Maximum comments after filtering; `0` means unlimited. |
| `fingerprint-mode` | `generic` | Fingerprint strategy: `generic`, `lint`, or `ai`. |
| `fingerprint-prefix` | `review` | Prefix used in hidden comment markers. |
| `dedupe` | `true` | Drop duplicate rendered comments in `post-file-comment`. |
| `fail-level` | `none` | Failure threshold: `none`, `any`, `info`, `warning`, or `error`. |
| `token` | `${{ github.token }}` | Token used for pull-request API access and comments. |

## Outputs

| Output | Description |
| --- | --- |
| `comments-posted` | Number of inline comments posted. |
| `item-count` | Items posted after filtering and existing-comment suppression. |
| `total-count` | Current findings before existing-comment suppression. |
| `skipped-existing-count` | Findings skipped because their comments remain open. |
| `resolved-count` | Earlier comments auto-marked fixed. |
| `should-fail` | `true` when the fail threshold was met. |
| `summary` | Generated or producer-provided summary. |
